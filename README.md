# flashcards-imba

Карточки для изучения английского, немецкого и французского. Слова, примеры,
цитаты из фильмов. Одна страница, никаких серверов, весь прогресс — на твоём устройстве.

| Язык | Слов | Подсказок | Цитат |
|---|---:|---:|---:|
| Английский | 5660 | 5660 | 1285 |
| Немецкий | 5544 | 5544 | 717 |
| Французский | 5287 | 5287 | 1005 |

После публикации на GitHub Pages приложение ставится иконкой на домашний экран
**iPhone и Android** — без App Store, без Google Play, без аккаунта разработчика.

## 1. Выложить на GitHub

### Способ А: через сайт GitHub, без git (можно даже с телефона)

1. Зайди на **github.com** → кнопка **+** справа сверху → **New repository**.
2. **Repository name:** `flashcards-imba`
3. Выбери **Public** (почему — см. «Важно про приватность» ниже).
4. Ничего больше не отмечай. Нажми **Create repository**.
5. На странице нового репозитория нажми **uploading an existing file**
   (ссылка в тексте посередине).
6. Перетащи туда **все файлы из этой папки**:
   ```
   index.html
   sw.js
   manifest.webmanifest
   icon-180.png
   icon-192.png
   icon-512.png
   icon-maskable-512.png
   favicon.png
   .nojekyll
   README.md
   ```
   Файл `.nojekyll` пустой, но нужен — без него GitHub может не отдать часть файлов.
   Если браузер не даёт перетащить файл, начинающийся с точки, нажми
   **Add file → Create new file**, впиши имя `.nojekyll`, оставь пустым и сохрани.
7. Внизу нажми **Commit changes**.

### Способ Б: через git, с компьютера

```bash
cd путь/к/этой/папке
git init
git add .
git commit -m "Flashcards 3.17.0"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/flashcards-imba.git
git push -u origin main
```

## 2. Включить GitHub Pages

1. В репозитории: **Settings** (шестерёнка сверху) → слева **Pages**.
2. **Source:** `Deploy from a branch`
3. **Branch:** `main`, папка `/ (root)` → **Save**.
4. Подожди 1–2 минуты и обнови страницу. Сверху появится адрес:

```
https://ТВОЙ_ЛОГИН.github.io/flashcards-imba/
```

**Запиши этот адрес.** Он не меняется никогда — ни при обновлениях, ни при
добавлении слов. Весь прогресс привязан именно к нему.

## 3. Поставить на телефон

### iPhone

1. Открой адрес **в Safari** (именно в Safari — в Chrome на iOS установка не работает).
2. Кнопка «Поделиться» внизу → **На экран «Домой»**.
3. Название → **Добавить**.

Появится иконка. Открывается на весь экран, без адресной строки, работает офлайн.

### Android

1. Открой адрес в **Chrome**.
2. Chrome сам предложит **«Установить приложение»**. Если не предложил:
   меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).

Приложение встанет как обычное: своя иконка, свой ярлык, работает офлайн.

## 4. Как обновлять

Заменить `index.html` и `sw.js` в репозитории на новые (в `sw.js` меняется номер версии — по нему телефон понимает, что пора обновиться). Остальные файлы трогать не нужно.

**Через сайт:** открой репозиторий → нажми на `index.html` → карандаш
(**Edit**) не годится для файла на 3 МБ, поэтому проще: **Add file → Upload files**,
перетащи новые `index.html` и `sw.js`, они заменят старые → **Commit changes**.

**Через git:**
```bash
cp /путь/к/новому/index.html .
git add index.html sw.js && git commit -m "Flashcards 3.17.0" && git push
```

Через минуту приложение на телефоне подхватит новую версию само: оно проверяет
обновление каждый раз, когда ты его открываешь.

### Прогресс при этом не пострадает

Прогресс хранится отдельно от базы слов и привязан к **устойчивым
идентификаторам карточек** (`en:apple`, `de:Apfel`, `fr:pomme`), а не к
номерам слов в списке. Поэтому можно спокойно добавлять слова в середину,
править переводы, менять уровни, удалять и возвращать слова — прогресс
останется на своих карточках. Это проверено автотестами.

Если слово убрали из базы — его прогресс не стирается, а откладывается.
Вернёшь слово — вернётся и прогресс.

Перед первым запуском каждой новой версии приложение само сохраняет
нетронутый снимок данных в IndexedDB (ключ `preupdate:<версия>`, хранятся
два последних) — на случай, если обновление окажется с багом.

### Единственное, что может сбить прогресс

**Смена адреса.** Браузер хранит данные по адресу страницы. Если открыть
приложение по другому адресу — например, скачать файл `flashcards-v146.html`
и открыть его отдельно, — для браузера это другой сайт, и там пусто.
Поэтому: один репозиторий, один адрес, файл всегда называется `index.html`.

## Как устроено приложение (с версии 3.0)

> **3.24: польский язык 🇵🇱 (пока уровень A1).** 1110 самых нужных слов по 18 темам — от частотного словаря польского, с примером и переводом к каждому. Род, часть речи и множественное число сверены со словарём Morfeusz (SGJP), примеры вычитаны. Род показывается так, как его показывают сами поляки: **ten · ta · to** (и **te** — только мн. ч.), есть тренировка «ten · ta · to». Работают «Сегодня», темы, Топ-1000, слово дня, «Царь горы», тест уровня, статистика, озвучка (польский голос). Пока нет: уровней A2–C2, цитат, форм глаголов и падежей — будут постепенно.

> **3.22: проверка всего приложения.** Исправлено: изменения последних долей секунды больше не теряются при синхронизации; счётчик «сегодня» сбрасывается в полночь, даже если приложение не закрывали; смена языка на другом устройстве закрывает открытую колоду вместо оценки чужих карточек; своё удалённое слово не передаёт звёздочку новому; «Напиши слово» считает проценты и принимает любой вариант («mein; meine»); «Повторить тему» снова проходит по всем словам темы, не трогая «Базу»; двойной тап при листании не оценивает следующую карточку; «Отменить» на последней карточке возвращает её; перенос слов в «Базу» тестом уровня не занимает норму новых слов; бонус за скорость в «Царе горы»; подсветка слов с умлаутами; импорт из таблиц с запятыми в переводе; переносы в стишках глаголов; крупнее мелкие кнопки; «sœur» вместо «soeur»; окончания («1 карточка», «1 день подряд»).

> **3.20: исправлены артикли** в немецкой и французской базе — 7 + 7 слов (das Debakel, das Verdikt, der Habitus, die Klientel, der Euphemismus, der Epigone, der Extremsport; le roman, le panégyrique, le piquant, le mâchicoulis, le carbone 14, l'enquête de satisfaction, l'iatrogénie). Прогресс по ним переезжает сам — по таблице переименований, вместе с уровнем и датой повторения.

* **Лекси** — компаньон на «Сегодня». Радуется, когда занимаешься, грустит и засыпает, если пропускаешь дни. Растёт по мере того, как берёшь слова в учёбу: Семечко → Росток → Побег → Цветок → Мудрец. Имя и выключатель — в настройках. На занятии маленький Лекси реагирует на ответы. За достижения открываются вещи для гардероба: шарфик, очки, медаль, корона и другие.
* **Попугайчик** — второй компаньон на выбор (Настройки → Оформление → Компаньон). Жёлтый волнистый самец с голубой восковицей, нарисован в плоском мультяшном стиле: мордочка к зрителю, тело боком, сложенное крыло вдоль спины и длинный хвост, по умолчанию его зовут «Лимончик»; у него своё имя, Лекси при этом никуда не девается. Те же настроения, но по-птичьи: наклоняет голову, машет крыльями, нахохливается, когда грустит, и прячет клюв, когда спит. Ступени: Птенец → Подросток → Взрослый → Хохолок → Мудрец. Если нажать на него, то через раз он вслух повторяет слово дня. Рост и гардероб у обоих компаньонов общие.
* **Цвета компаньонов** — Настройки → Оформление, под выбором компаньона. У попугайчика шесть окрасов, как у настоящих волнистых: жёлтый, зелёный (жёлтая маска), голубой, фиолетовый, серый (белая маска) и белый. У Лекси шесть цветов: мята, небо, роза, лаванда, апельсин, лимон. У каждого компаньона свой цвет; выбор синхронизируется вместе с остальными настройками.
* **Сегодня** — порция на день: повторения, которые пора сделать, плюс новые слова (10 в день, меняется в настройках). Одна кнопка «Начать». Ниже — календарь месяца (дни занятий и повторения по плану), план на неделю, статистика и достижения.
* **Слова** — уровни, темы и все слова с состоянием: знаю / учу / новые. Поиск, фильтры «Учу», «Трудные», «⭐», «Свои». Тему можно поставить «учить первой» или просто пролистать.
* **Слово дня** (на «Сегодня») — одно частое слово из «Топ-1000», которое ты ещё не учишь, с цитатой и переводом. «Учить» — сразу в сегодняшнюю порцию, «Уже знаю» — отметить знакомым.
* **Свайпы** (удобно на iPhone): вправо — «Знаю», влево — «Не знаю», вверх — «Знаю на 100%». До переворота свайп просто переворачивает карточку. В цитатах свайп — следующая цитата.
* **Части речи.** На каждой карточке цветная метка: сущ., гл., прил., прич., нареч., мест., числ., предл., союз, частица, артикль, межд., выраж. На обороте — множественное число: у немецких существительных всегда (das Haus → die Häuser), у английских и французских — только нестандартное (child → children, cheval → chevaux). Во вкладке «Слова» есть фильтр «Части речи»: группу можно пролистать или поставить «учить первыми».
* **Топ-1000** (во вкладке «Слова») — 1000 самых частых слов каждого языка по частотному словарю, по порядку. Можно «учить первыми» — тогда новые слова на «Сегодня» пойдут строго по частоте. Ступени 100 → 300 → 500 → 1000, за каждую — достижение.
* **Практика** — пропуски в предложениях, на слух, «Напиши слово», «Царь горы», цитаты. Ответы тоже засчитываются в повторения.
* **Глаголы дня** (на «Сегодня», с версии 3.23) — 3 неправильных глагола в день: сначала те, что уже учишь, потом новые по частоте. «Тренировать» — и после трёх ответов снова «Сегодня». Кнопка есть и в итоге занятия. Выключается в Настройки → Повторения.
* **Артикли** (с версии 3.23) — у знакомых немецких и французских существительных примерно каждое третье на «Сегодня» спрашивается так: «? Zeitung» и кнопки der · die · das (le · la). Карточка откроется после ответа; «Не знаю артикль» — показать правильный. Отдельная тренировка в «Практике»: 20 слов, сначала из тех, что учишь. Клавиши 1/2/3 тоже работают. Выключается в настройках.
* **Цель недели** (на «Сегодня») — сколько карточек пройти с понедельника по воскресенье (35…210, по умолчанию 70), полоска и подсказка «≈ N в день». За выполненные недели — достижения и вещи в гардероб: 🥳 колпак за первую, 🎧 наушники за четвёртую.
* **Статистика** (на «Сегодня», «Мой прогресс») — сколько слов знаешь и учишь на каждом уровне A1…C2, рост «знаю» по последним 8 неделям и трудные слова месяца (сколько раз забывал за 30 дней).
* **Светлая тема** и **«Авто»** (Настройки → Оформление → Тема): «Авто» следует за iPhone — днём светлая, ночью Фиалка.
* **Слово дня на iPhone** (Настройки → Прогресс → синхронизация GitHub) — в тот же приватный Gist кладётся файл со словом дня. Ссылку на него можно вставить в приложение «Команды»: «Получить содержимое URL» → «Показать уведомление», плюс «Автоматизация» на 9:00 — и каждое утро приходит уведомление со словом. Слово обновляется при синхронизации. Учти: по этой ссылке файлы Gist может открыть любой, у кого она есть, — не публикуй её.
* **Тест уровня** (в «Практике», с версии 3.20) — слова от A1 к C2, по 6 на ступень: выбираешь перевод или честно жмёшь «Не знаю». 4 из 6 — ступень взята, иначе тест заканчивается. В конце — уровень, примерный запас слов и три действия: отправить угаданные слова в «Базу», отправить в «Базу» все слова взятых уровней (с подтверждением и кнопкой «Отменить») или открывать темы со следующего уровня. Слова из «Базы» тест не спрашивает. Перенос в «Базу» не считается занятием дня.
* **Царь горы** — теперь для всех трёх языков (с версии 3.20): гора строится из слов выбранного языка. Рекорды у каждого языка свои; английские — на прежнем месте.
* **Цвет рода** (немецкий и французский, с версии 3.20) — у существительных цветная полоска сверху карточки, метка с артиклем и артикль в цвете: der / le — синий, die / la — красный, das — зелёный, только мн. ч. — фиолетовый. Метка есть и у слов, записанных без артикля (lettre → la, l'œuf → le, Frau → die). Слова, которые бывают обоих родов (l'élève, l'artiste), без цвета. Выключается в Настройки → Оформление.
* **Формы глаголов** (в «Практике») — неправильные глаголы: английский (161, go – went – gone), немецкий (167, gehen – ging – ist gegangen + «er geht»), французский (77, présent je · nous · ils + passé composé и futur). Три вкладки: **Стишки** — короткие смешные стихи, в рифму которых вплетены формы (написаны специально для приложения), **Таблица** с поиском и **Тренировка** по 10 глаголов: вспомни формы → «Помню»/«Не помню»; после четырёх «Помню» подряд глагол считается выученным.
* **Цитаты** разложены по категориям во всех трёх языках, плюс «все вперемешку», избранные и свои:
  * английский — Marvel, DC, фантастика, фэнтези, мультфильмы, мультсериалы и аниме, видеоигры, боевики, ужасы, комедии, спорт, драма;
  * немецкий — пословицы, идиомы, крылатые выражения, Гёте/Шиллер и классика, Библия и Лютер, кино и сериалы, ТВ и юмор, политика и история;
  * французский — пословицы, выражения, кино и сериалы, мультфильмы и комиксы, литература, мыслители и учёные, история и политика, искусство и мода.
* **Настройки** — повторения, оформление, озвучка, «Царь горы», свои слова, резервная копия.
* **Стиль карточек** (Настройки → Оформление → Карточки, с версии 3.21) — один и тот же на «Сегодня» и при листании тем. «Во весь экран»: большой лист, ответ открывается под словом. «Карточка»: карточка одного размера, всегда по центру экрана, при нажатии переворачивается, на обороте — перевод; её можно вертеть туда-обратно сколько угодно. Во весь экран повторное нажатие прячет и снова показывает ответ. Выбор синхронизируется вместе с остальными настройками.
* **Оформление** (в настройках) — 6 тем приложения (Фиалка, Океан, Графит, Вишня, Кофе, Полночь) и 6 видов бумаги для карточек (клетка, линейка, старая бумага, сепия, сирень, тёмное стекло). Выбор сохраняется вместе с прогрессом.

**Как работает изучение (с версии 3.17).** У каждого слова одно из трёх состояний: **новое**, **на изучении** (уровень 0–6) или **в «Базе»** (знаешь на 100%, больше не показывается).
На карточке — одинаково на «Сегодня» и при листании — три ответа (сначала переверни карточку):
* **✗ Не знаю** (свайп влево) — слово уходит на изучение с нуля и вернётся через пару карточек;
* **✓ Знаю** (свайп вправо) — уровень +1, слово вернётся позже: 1 день → 3 дня → неделя → 2 недели → месяц → 2 месяца; после «Знаю» на 6-м уровне оно само уходит в «Базу»;
* **💯 Знаю на 100%** (свайп вверх) — сразу в «Базу».
После ответа сверху на пару секунд всплывает «вернётся через …» с кнопкой **«Отменить»**. Промахнулся позже — «Слова» → фильтр **«💯 База»** → нажми на слово → «Вернуть на изучение». Нажатие на любое слово в списках открывает такое же меню.
«Знаю» в статистике и достижениях — слова из «Базы» и слова 4+ уровня (помнишь 2 недели и дольше).

## Напоминание позаниматься

«Настройки» → «Напоминание». Выбери время, дальше два способа (можно оба):

* **📅 Добавить в календарь** — самый надёжный, работает везде, включая iPhone. Скачается файл `flashcards-reminder.ics`;
  открой его и нажми «Добавить» (на iPhone — «Добавить все»). В календаре появится ежедневное событие со звуком
  в выбранное время. Убрать — удалить событие в календаре.
* **🔔 Уведомление от приложения** — напоминает, только если сегодня ты ещё не занимался:
  * на **Android** с установленным приложением — в фоне, но время выбирает сам Android, поэтому может прийти с опозданием;
  * на **компьютере** — пока открыта вкладка с приложением;
  * на **iPhone** — только пока приложение открыто. Фоновые уведомления на iPhone требуют своего сервера, которого у приложения нет,
    поэтому для iPhone — календарь.

## 5. Резервная копия и перенос между устройствами

В приложении: вкладка **«Настройки» → «💾 Сохранить / восстановить прогресс»**.

* **Скачать копию** — файл JSON с прогрессом и настройками (базы слов внутри нет).
* **Загрузить копию** — сливает копию с тем, что уже есть. Ничего не затирается:
  для каждой карточки и каждой настройки выигрывает более свежее изменение.
  Копия из старой версии нормально восстанавливается в новой.
* **Код прогресса** — то же самое, но строкой, чтобы переслать себе в мессенджер.

### Автоматическая синхронизация через GitHub (с версии 3.11)

Прогресс сам переносится между телефоном и компьютером через **приватный Gist** на твоём аккаунте GitHub.

1. В приложении: **«Настройки» → «Прогресс» → «Синхронизация через GitHub»** → ссылка **«1. Создать токен на GitHub»**.
   Откроется GitHub с уже отмеченным правом **gist** — больше ничего отмечать не нужно.
   Срок (Expiration) можно поставить «No expiration» или год. Нажми **Generate token** и скопируй его (`ghp_…`).
2. Вставь токен в поле и нажми **«Подключить»**. Приложение создаст приватный Gist `flashcards-progress.json`.
3. На втором устройстве сделай то же самое **с тем же токеном** — оно найдёт этот Gist и подтянет прогресс.

Дальше всё само: при открытии приложения, при сворачивании и раз в 20 секунд во время занятий.
Слияние то же, что и у резервной копии, — для каждой карточки побеждает более свежая правка, поэтому
можно заниматься на двух устройствах по очереди или даже одновременно.

* Токен хранится **только на устройстве** и не попадает ни в Gist, ни в резервную копию.
  У токена одно право — работать с Gist; к репозиториям и остальному аккаунту доступа у него нет.
* «Отключить синхронизацию» стирает токен с устройства. Сам токен можно отозвать на github.com → Settings → Developer settings → Personal access tokens.
* Резервная копия файлом по-прежнему работает и не зависит от синхронизации.

**Где работает.** Подключай синхронизацию в приложении, открытом **по твоему адресу GitHub Pages**
(`https://ТВОЙ_ЛОГИН.github.io/…`) или с иконки на домашнем экране. В превью внутри Claude и в файле,
открытом прямо с диска, запросы к GitHub, скорее всего, будут заблокированы.

**Как понять, что всё работает.**
* В панели синхронизации зелёная строка: «✓ Подключено · синхронизировано 2 окт., 18:41» — время последнего обмена с GitHub.
* На [gist.github.com](https://gist.github.com) (под своим аккаунтом) появится секретный Gist
  «Flashcards — прогресс…» с файлом `flashcards-progress.json`. Его не нужно открывать или править — приложение делает всё само.
* Кнопка «Синхронизировать сейчас» — если не хочется ждать 20 секунд (например, перед тем как взять другое устройство).

**Если что-то пошло не так** — приложение пишет причину прямо в панели:

| Сообщение | Что значит | Что делать |
|---|---|---|
| «Токен не подошёл или истёк» | токен неверный, отозван или закончился его срок | создать новый токен по ссылке и подключить заново на **всех** устройствах |
| «GitHub временно ограничил запросы или у токена нет права „gist“» | при создании токена не отмечено право **gist**, либо слишком много запросов | создать токен заново по ссылке из приложения (право уже отмечено) или подождать час |
| «Gist не найден» | Gist удалили на GitHub | «Отключить синхронизацию» → подключить снова: создастся новый Gist с текущим прогрессом |
| «Нет связи с GitHub» | нет интернета или GitHub недоступен | ничего: прогресс сохранён на устройстве и отправится, когда связь появится |

Синхронизация проверена автотестами на имитации GitHub (два устройства, правки с обеих сторон,
неверный токен, отключение). Если при подключении к настоящему GitHub появится ошибка, которой нет в таблице, —
пришли её текст, это поможет быстро поправить.

**Срок токена.** Если при создании выбрать срок (например, 90 дней), по его окончании синхронизация остановится
с сообщением «Токен не подошёл». Прогресс при этом не теряется: создай новый токен и подключи его на каждом устройстве.

## Важно про приватность

На бесплатном аккаунте GitHub Pages работает **только для публичных репозиториев**.
То есть содержимое приложения — включая цитаты из фильмов — будет доступно
по прямой ссылке любому, кто её знает. Индексации в поиске почти наверняка не
случится, но формально это публикация.

Если это не устраивает, есть варианты с приватным репозиторием:

* **Cloudflare Pages** — бесплатно, подключается к приватному репозиторию GitHub.
* **Netlify** — то же самое, бесплатный тариф.
* **GitHub Pro** — Pages для приватных репозиториев.

Инструкция по установке на телефон одинаковая: всё решает постоянный HTTPS-адрес.

## Настоящий .apk для Android

PWA на Android и так ставится как приложение, но если нужен именно файл `.apk`
(например, чтобы поставить без магазина или раздать):

1. Сначала опубликуй сайт по шагам выше.
2. Зайди на **pwabuilder.com**, вставь адрес приложения.
3. **Package for stores** → **Android** → скачается подписанный `.apk`.

Для iPhone аналога нет: `.ipa` собирается только на macOS в Xcode и требует
аккаунта Apple Developer (99 $ в год). Установка через Safari «На экран Домой»
даёт ровно тот же результат — полноэкранное приложение со своей иконкой.
