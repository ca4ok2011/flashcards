flashcards-imba v144
====================

Что в архиве:
  index.html            — само приложение
  sw.js                 — service worker: кэширует ТОЛЬКО файлы приложения,
                          прогресс (localStorage/IndexedDB) не трогает никогда
  manifest.webmanifest  — иконка и полноэкранный режим
  icon.png              — иконка

Как обновлять (каждые 5-10 минут — безопасно):
  Заменить index.html (и при желании sw.js) на новые файлы. Прогресс не пострадает:
  он хранится отдельно, привязан к ID карточек, а не к их номерам в списке.

Если открывать файл напрямую (file://):
  Работает всё, кроме service worker — он требует http(s). Это нормально.

Резервная копия:
  «Сохранить / восстановить прогресс» → «Скачать копию». Файл JSON с прогрессом
  и настройками, без базы слов. Копия из старой версии восстанавливается в новой.

Точка восстановления:
  При первом запуске каждой новой версии приложение само кладёт нетронутый снимок
  данных в IndexedDB (ключ preupdate:<версия>), хранит два последних.
